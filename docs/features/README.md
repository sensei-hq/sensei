# Features

The FR/NFR registry — the "what". Each feature is a dossier that mirrors
the project shape:

```
<feature>/
  brief.md        # intent-level: user objective + data (not layout)
  design.md       # depth dialed by risk; cross-layer contract
  mockup-ref.md   # link to a section of the system mockup (optional; added later)
  plan.md         # tasks
  tests/          # acceptance
  decisions.md    # learnings
```
