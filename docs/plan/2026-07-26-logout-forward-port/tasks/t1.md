# t1 — Update develop's logout route to the robust polling signOut

## What
Replace `dojo/src/routes/logout/+page.svelte` on develop with main's robust version: in
`onMount`, **poll briefly** for `kavach.signOut` (up to ~40× / 50ms) before calling it, so a
full navigation to `/logout` that mounts before the async kavach hydration still signs out;
then `goto('/signin', { invalidateAll: true })`.

## Why
develop's current version calls `signOut` immediately — if kavach hasn't hydrated yet,
`signOut` is `undefined` and logout silently no-ops. main's polling fixes the mobile
full-navigation race (`6b0f78d1`).

## How

Keep the `<div>Signing out…</div>` markup + the `public` kavach rule unchanged.
