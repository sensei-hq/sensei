# Sensei HQ Hub + Sensei Site (one combined website) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use `- [ ]`. When editing `.svelte` files, use the **svelte:svelte-file-editor** agent / Svelte MCP; for styling use **sensei:semantic-styles-rokkit**; follow the project **mockup-porting rule** (inline literal OKLCH from the mockup tokens; render the artboard before trusting the JSX).

**Goal:** Make the `website/` app serve the **Sensei HQ hub** at `/` and the existing **Sensei site** under `/sensei`, in one SvelteKit/adapter-static GitHub Pages deploy reusing the existing rokkit + zen/sumi design system.

**Architecture:** One SvelteKit app. Thin global root layout (theme only). Hub is `/+page.svelte` + `lib/components/hub/*`. Sensei site moves wholesale under `routes/sensei/` with its own `sensei/+layout.svelte`. Org legal pages (`/privacy`, `/terms`) stay at root. Deploy serves at domain root (drop `BASE_PATH=/sensei`); canonical `sensei-hq.com`. Treat as a fresh release — no old-URL redirects.

**Tech Stack:** SvelteKit (Svelte 5 runes), `@sveltejs/adapter-static`, UnoCSS + rokkit (`@rokkit/states` `vibe`, `@rokkit/actions` `themable`), zen/sumi tokens, Playwright (e2e), bun.

**Spec:** `docs/superpowers/specs/2026-06-13-hub-site-design.md`. **Hub source mockup:** `docs/mockups/Sensei/hq/site.jsx` (669 lines) + `docs/mockups/Sensei/Sensei HQ.html`. **Full zen-sumi tokens (reference):** `docs/mockups/Sensei/site/tokens.css`.

All paths below are relative to `website/` unless noted. Run commands from `website/` (`cd website`). Package manager: **bun** (root `package.json` has no packageManager field; `website/bun.lock` → bun).

- [ ] **Step 1: Write `tests/hub.spec.ts`:**
```ts
import { test, expect } from '@playwright/test';

test('hub renders at / with all sections', async ({ page }) => {
  await page.goto('/');
  await expect(page).toHaveTitle(/Sensei HQ/);
  for (const id of ['products', 'approach', 'open']) {
    await expect(page.locator(`#${id}`)).toBeVisible();
  }
});

test('Sensei product card links internally to /sensei', async ({ page }) => {
  await page.goto('/');
  const sensei = page.getByRole('link', { name: /Sensei/ }).first();
  await expect(sensei).toHaveAttribute('href', /\/sensei$/);
});

test('external product cards point at subdomains in a new tab', async ({ page }) => {
  await page.goto('/');
  for (const [name, host] of [['DBD','dbd'],['Rokkit','rokkit'],['Kavach','kavach']]) {
    const card = page.getByRole('link', { name: new RegExp(name) }).first();
    await expect(card).toHaveAttribute('href', new RegExp(`https://${host}\\.sensei-hq\\.com`));
    await expect(card).toHaveAttribute('target', '_blank');
  }
});
```
